## 0. 一句话

A2 机器狗背着 AIRBOT 机械臂，在杂乱室内导航到目标物体，自己选择最适合夹取的方向和位置，然后触发一个**预训练、冻结的夹取网络**把物体夹起来。
DreamerV3（照搬 AirDreamer 的在线训练方式）负责导航，以及"何时、在哪里触发夹取"。
**贡献点**：在世界模型中学习主动选择夹取方向和夹取时机（active grasp）。

## 1. 与 v3 的主要变化

| 项 | v3（旧） | v4（新） |
|---|---|---|
| 任务 | 导航 → 抓取 → 导航 → 放置 | 导航 → 夹取，**不做放置**【已定】 |
| 夹取 | Dreamer 内的 pick 技能头，端到端学习 | **Isaac 中用 PPO 预训练，冻结**，作为 Dreamer 外部的一个分支【已定】 |
| 技能切换 | skill 离散头（NAV/PICK/PLACE）+ 可行性先验 + 切换惩罚 | Dreamer 输出一个离散动作 `trigger`（继续导航 / 触发夹取）【建议，用户倾向同意】 |
| 选择夹取方向 | 隐式（可行性头） | 显式：按扇区设计的势函数奖励【已定方向，参数待调】 |
| 底盘与夹取 | pick 头带底盘微调 ±0.15、机身高度 | 夹取时底盘不动、固定站姿高度；要不要挪底盘由 Dreamer 在导航阶段决定【已定】 |
| 信息流 | — | 夹取 → Dreamer（夹取网络的成功率估计作为 Dreamer 的输入），**不**反向【已定】 |

## 3. 环境（第一阶段：kin 后端）

- 复用：场景生成（6 类场景）、kin 运动学后端、D435i/D405 深度渲染、域随机化、目标提供器（带噪声）、场景过滤。
- 物体：70% 立起的扁盒（厚 3–5 cm、宽 10–14 cm、高 12–15 cm，只能从窄面夹）+ 30% 圆柱。不允许俯抓。【已定】
- 去掉：放置区、PLACE 技能、place 动作头。
- 控制频率 5 Hz；回合最长 450 步（90 s），nav-only 后可考虑缩短到 300【待定】。

### 3.1 观测
- `depth_head`、`depth_wrist`：48×80 uint8（沿用）
- `proprio`：28 维（沿用；去掉与放置相关的项，如有）
- `goal`：16 维（物体相对位置，带噪声 / 延迟 / 丢失，沿用）
- （第二阶段，可选）`grasp_score`：标量 ŝ，见 §7

### 3.2 动作【建议】
- `nav`：连续 3 维 vx ±0.8 m/s、vy ±0.4 m/s、wz ±1.0 rad/s。**去掉机身高度维度**：夹取固定在站姿，导航阶段不需要控制高度（Q17）。
- `trigger`：离散 {0 = 继续导航, 1 = 触发夹取}。
- 当前代码的 DreamerV3 已支持 dict 动作空间中离散与连续混合（`policy_dist_disc: categorical`，`policy_dist_cont: bounded_normal`），所以 v4 可以**直接关掉 skill 机制**（skill 头、可行性先验、切换惩罚），变成接近原版 AirDreamer 的结构。

### 3.3 trigger 的语义【建议】
- 物体与机械臂肩部的距离 > 1.0 m 时触发：**无效**，不结束回合，奖励 −0.1，避免训练初期乱按导致回合立即结束。
- ≤ 1.0 m 时触发：底盘停下，执行冻结夹取分支（内部最多 K 步，例如 60 步 = 12 s），结束后返回**一条**转移：reward = 成功/失败奖励，is_last = is_terminal = True。
  - 在世界模型里，"触发"就是一步，直接预测结果，类似 SkiMo 的技能结果预测。奖励头因此会隐式学到"在这里夹，成功率多大"。
- 一次触发就结束回合（v1）。是否允许失败后重试（最多 N 次）见 Q19。

## 4. 奖励【参数待用户微调】

### 4.1 位姿质量 q(s) ∈ [0, 1]（扇区设计 v1）
q 只用来算奖励，可以使用特权信息（物体真实朝向）。策略只能看到深度图，必须自己推断朝向。

- φ：机器人到物体连线方向，与最近一个"好方向"之间的夹角，取值 0–90°。
  - 扁盒：好方向是沿物体宽度轴的 0° 和 180°，即正对两个窄面。
  - 圆柱：任何方向都是好方向，φ ≡ 0。
- 扇区权重 w(φ)：

| 扇区 | φ | w | 依据 |
|---|---|---|---|
| A 最佳 | ≤ 15° | 1.0 | 几何推导：平行夹爪需张开的宽度 = t·cosφ + w·sinφ，必须 ≤ 8 cm。手腕不转时，最难物体（t5/w14）允许 φ ≤ 12.7°，最易物体（t3/w10）允许 φ ≤ 约 33°。取 15°，大致对应"手腕不转就能夹" |
| B 可接受 | 15–35° | 0.7 | 经验值，假设手腕可以转一部分来补偿，**无推导** |
| C 勉强 | 35–60° | 0.3 | 经验值，**无推导** |
| D 正对宽面 | > 60° | 0 | 宽面 10–14 cm 超过开口 8 cm |

- 某个方向的接近通道被墙、柜子或障碍物挡住：该方向按 D 处理（复用 `scene.approach`）。
- 距离项 g_dist(d)：物体到肩部的距离 d ∈ [0.30, 0.55] m 时为 1，区间外平滑衰减到 0。**经验值**，按臂展 0.27+0.29+0.24=0.80 m 的 40%–70% 取。
- 朝向项 g_head(ψ)：物体在机身坐标系中的方位 |ψ| ≤ 20° 时为 1，≥ 45° 时为 0。**经验值**。
- q(s) = w(φ) · g_dist(d) · g_head(ψ)
- 上述所有经验值，等夹取网络的成功率地图（§6.3）出来后都用实测替换：q(s) := 实测成功率(s)。

### 4.2 奖励项

| 项 | 默认值 | 说明 |
|---|---|---|
| 位姿引导 | λ·(γ·q(s′) − q(s))，λ = 5，γ = Dreamer 的折扣（horizon 333 → 0.997） | 势函数形式（Ng、Harada、Russell 1999）：不改变最优策略，停在原地刷不到分。终止时势能 Φ = 0 |
| 接近物体 | 势函数形式，系数 2，沿用现有 w_nav | 远距离时的引导 |
| 触发：成功 | S = +20 | 回合结束 |
| 触发：失败 | −F，F 默认 10 | 回合结束。最低触发把握 p* = F/(S+F)：F=5→0.2，10→0.33，20→0.5（Q16） |
| 无效触发（距离 > 1 m） | −0.1 | 不结束回合 |
| 碰撞 | −2 | 沿用 |
| 时间 | −0.01/步 | 沿用 |
| 平滑 | w_smooth 0.01 | 沿用 |
| （可选）早期辅助 | 触发时额外 +5·q，前 30 万次更新内退火到 0 | 帮助早期学习，默认关闭 |

DreamerV3 会按回报的 5%–95% 分位数归一化，所以重要的是各项比例，不是绝对大小。

## 5. 夹取代替模型（kin 阶段使用）【建议，Q18】

在 Isaac 夹取网络训好之前，kin 环境里要用一个"冻结夹取分支"的代替品。两个选项：

- **方案 A（推荐）**：直接用现有的脚本专家 `ManipController`（expert.py）。锁住底盘微调和机身高度（站姿），只让机械臂和夹爪闭环执行：预抓取 → 接近 → 闭合 → 抬起。成功与否用 kin 现有的判据：宽度检查、IK、关节限位、碰撞、held_bottom。
  - 优点：扇区、遮挡、够不着等效应会自然出现；也能在 kin 里先测一张"代替模型的成功率地图"，把整套流程跑通。
- **方案 B**：解析概率，success ~ Bernoulli(q(s) × 几何可行)。实现快，但和真实夹取网络差得更远。

## 6. 冻结夹取网络（Isaac，与 kin 阶段并行进行）

### 6.1 已定规格
- 训练：PPO，用状态机（脚本控制器）采集数据作为教师，先做 BC 或 DAgger 初始化，再用 PPO 微调。【已定】
- 输入：头部深度 + 腕部深度（+ 本体感知）。【已定】
- 夹取时机身固定在站姿高度，底盘不动。【已定】
- 有效夹取范围：先测试，之后由用户调整（大致 50 cm 以内，未确认）。【待定】

### 6.2 待定
- "成功"的定义：例如抬起 ≥ 5 cm 并保持 1 s。
- PPO 的 critic 用不用特权信息？如果用，它在真机上算不出来，就不能作为 Dreamer 的输入（Q15）。
- 地面物体：站姿下肩部离地约 0.6 m（0.385 + 0.095 + 0.117），扁盒夹持点约 7 cm 高，又不允许俯抓，可能够不着（Q14）。

### 6.3 成功率地图（替换 q 的依据）
- 网格：
  - 距离 0.20–0.80 m，步长 0.05
  - 方位 ±45°，步长 5°
  - 物体相对朝向 0–90°，步长 10°
  - 物体高度：地面 / 桌面 / 柜内
  - 形状：扁盒 / 圆柱
- 每格至少 20 次试验。
- 输出：成功率表 + 拟合的平滑函数 → 替换 §4.1 中的 q。

## 7. 夹取 → Dreamer 信息流（第二阶段，作为扩展或消融）【建议】
- 第一版不接这条输入。Dreamer 只通过"触发后的成功或失败奖励"学会判断能否夹取。
- 夹取网络训好后，蒸馏一个**只看深度**的成功率预测器 ŝ（依据：从当前位姿执行夹取，成功的概率），作为 Dreamer 的一路标量观测。
- 消融对比：有 ŝ / 无 ŝ。
- 原有的可行性头（aff head）可以改造成辅助头，预测 q 或实测成功率【待定，Q21】。

## 8. 训练流程【已定】

1. **阶段 A（kin）**：代替模型 + 扇区 q，用 DreamerV3 在线训练，把整套流程和奖励调通。参数沿用 v3 的在线配置：size50m、32 个环境、train_ratio 32、batch 16×128、replay 1e6、lr 4e-5、想象步长 30。
2. **阶段 B（Isaac，与 A 并行）**：训练 PPO 夹取网络，测出成功率地图。
3. **阶段 C（kin）**：用夹取网络的成功率地图替换 q 和代替模型，重新训练或微调 Dreamer。
4. **阶段 D（Isaac）**：Dreamer 加冻结夹取网络，在 Isaac 中在线微调，然后上真机。

## 9. 评测

### 9.1 指标
- 夹取成功率（总体、分场景类型、分形状）
- 接近角误差：触发时的 φ
- 到夹取的时间（步数）
- 误触发率：触发但失败的比例
- 碰撞次数
- 遮挡场景下的表现，例如另一个窄面被挡、需要绕路的情况

### 9.2 基线 / 消融
| 名称 | 内容 | 要回答的问题 |
|---|---|---|
| B-near | 导航到最近点就触发夹取，不选方向 | 选方向是否有用 |
| B-geo | 几何启发式：规划器直接挑最佳面走过去再触发（改造现有脚本专家） | 学出来的方法是否比手工规则强，尤其在遮挡或朝向不确定时 |
| B-rule | Dreamer 导航 + 手写"奖励不涨 N 步就触发"规则（导师最初的想法） | 学出来的触发是否优于平台检测 |
| B-noq | Dreamer，不加扇区引导奖励 | 引导奖励的作用 |
| B-ppo | PPO，用同样的奖励 | 为什么要用世界模型 |
| 记忆消融 | 每步把 RSSM 的确定性状态清零 | 记忆在主动观察中的作用 |
| ŝ 消融 | 有 / 无夹取网络成功率输入 | 夹取 → Dreamer 信息流的作用 |
