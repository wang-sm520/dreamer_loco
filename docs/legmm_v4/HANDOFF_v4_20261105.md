## 3. v4 框架（标记：【定】用户已拍板；【议】Opus 提出，未确认）

### 任务和两层结构
- **任务**：导航到物体前，自己选择接近的方向和站位，触发冻结夹取技能。不做放置。【定】
- **上层 DreamerV3**（照搬 AirDreamer 在线训练）【定】
  - 动作：`nav = (vx ±0.8, vy ±0.4, wz ±1.0)`，外加离散 `trigger` ∈ {继续, 夹取}。
  - 去掉机身高度维度。
- **下层夹取技能**【定】
  - 在 Isaac 中训练：状态机当教师，先 BC 后 PPO。
  - 输入头部 + 腕部深度。
  - 夹取时保持站姿高度（0.385 m），底盘不动。
  - 训好后冻结。
- **两层关系**【定】
  - 网络独立，不共享可训练部分。
  - 信息只从夹取流向 Dreamer。第二阶段可以加入一个可部署的成功率预测器 ŝ，作为扩展或消融。

### 触发语义【议】
1. trigger=1 时先过安全门。安全门等于"技能起始集合"，包括：
   - 距离、方位、物体高度落在技能包络内；
   - 目标估计有效且未过期；
   - 底盘已停稳；
   - 机械臂处于收起状态。
   安全门**不判断**夹取是否可行。
2. 不满足安全门：触发无效，奖励 −0.1，回合继续。
3. 满足安全门：
   - 刹停 settle：发零速度，直到线速度 < 0.05 m/s 且角速度 < 0.1 rad/s，最多等 1.5 s；
   - 冻结技能从停稳后的真实位姿开始执行；
   - 回合终止。
4. 450 步超时算作截断（继续 bootstrap），不是终止。

### 成功与奖励
- **成功**【议】：物体抬离支撑面 ≥ 5 cm，保持 ≥ 2 s，没有掉落，机械臂没有碰撞，在宏动作时限（约 15 s）内完成。
- **奖励**【定方向，数值议】：

| 项 | 数值 |
|---|---|
| 成功 | +20 |
| 失败 | −F，F 先取 10，之后比较 5 / 10 / 20 |
| 无效触发 | −0.1 |
| 碰撞 | −2 |
| 时间 | −0.01 / 步 |

- **q\***【议】：用物体真实位姿算出的扇区质量，只在训练时作为势函数 shaping 使用。
  - 公式：r = γΦ(s′) − Φ(s)，终止这一步的 shaping 为 −Φ(s_before)。
  - q\* 不进策略观测，也不进安全门。
  - 必须做"去掉 q\*、只用稀疏奖励"的消融。
- **三个 q 的符号必须分开用**：
  - q\*：真值，只用于奖励；
  - q̂：由估计位姿算出；
  - ŝ：学出来的成功率预测。

### 辅助头、观测与场景
- **可行性辅助头**【议，G4】
  - 世界模型里加一个辅助头，预测"从当前状态触发能否成功"。
  - 标签来自用冻结技能做的反事实执行；kin 阶段用代替模型。复用原来的 labeler。
  - 只作为辅助损失，不作为输入。
- **观测**【议，G3】
  - 深度 48×80（头部 + 腕部）、本体感知、目标位置。
  - 主实验不给物体 yaw。现有 goal 里有 sin/cos(yaw)，噪声约 0.1 rad，**必须去掉**。
  - 对照实验给一个随视角变化的带噪声 yaw 估计。
- **场景**【议，G1】
  - v1 只做桌面场景，去掉地面物体；CUBBY 架高后放到后期。
  - 桌面场景要重新设计：物体离桌沿的距离要在可达范围内；桌子有多条边可接近，其中部分被挡住；物体相对桌边的朝向要有分布。

### 研究定位
- 贡献点是：在部分可观测下，配合冻结技能，做"可行性感知的主动接近"。具体就是在遮挡和朝向不确定时，选择从哪个面接近、何时停止观察并触发。
- 不要把"学到触发时机"本身当作主要贡献，也不要声称"首次"。

## 8. 操作要点和坑

**派 Codex 的命令**（在 air-5090 上）

- 追问用 `codex exec resume --last`。
- workspace-write 沙箱在这台机器上不能用（bwrap 回环报错），所以只能用 danger-full-access，并在任务里写明限制：不提交、不碰 main、`~/data`、`~/logdir/legmm/m3`。

**ssh 与进程**
- ssh heredoc 里带单引号容易出错。做法：先在本地写好文件，再 scp 过去。
- `pkill -f` 会把自己的 ssh 命令也杀掉。查进程用 `pgrep -f "pattern[x]"` 这种写法。

**审核 Codex 时重点看**
- 有没有"恒真"的测试：它以前写过 `rate >= 0` 这种断言，也写过故意放在远处的状态，测试永远能过。

- 测试用 `python -m pytest tests/legmm -q -p no:warnings`，大约 7–10 分钟。

**配置的坑**
- `configs.yaml` 里的正则预设会按前缀匹配：`.*\.depth` 会匹配到所有以 depth 开头的键。所以新建的键不要以 depth / units / layers / rssm / bins 开头。
- `elements.Config` 不接受空列表，会丢掉空字典，遇到未知键会报错。

**网络限制**
- 从 air-5090 访问 Anthropic API 返回 403。
- 本机访问 raw.githubusercontent.com 会被 SSL 拦截。

**回归要求**
