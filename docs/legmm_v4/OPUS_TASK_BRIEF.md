## 2. 场景

- 只做桌面，桌上只有目标。遮挡和被挡的桌边来自墙和家具。
- 不做 LOW_FLOOR，CUBBY 移出主实验。
- 桌高 0.50–0.65 m，物体离最近桌沿 0.05–0.25 m，沿桌边均匀随机（用户 2026-11-05 按审计结果定）。
- 被挡桌边：50% 不挡，50% 挡最近桌边（用户定）。过滤不可解场景后，被挡场景里的物体会偏向桌角，因为桌边中段挡住最近桌边后只有 16.4% 可解；要在统计里报告这个偏置。
- 桌面宽 0.6–1.2 m、深 0.6–1.0 m，物体朝向 0–180° 均匀【默认】。
- 物体：70% 立起的扁盒（厚 3–5、宽 10–14、高 12–15 cm，只能从窄面水平夹取），30% 圆柱。禁止俯抓。圆柱是不需要选角度的对照，结果分层报告。
- 不可解场景：训练和验证只保留至少有一个可行站位的场景；测试同时报过滤后、未过滤的成功率和过滤比例。
- 可解性必须按固定底盘、固定站高的技能重新判断。旧 `scene_solvable()` 只能证明旧专家可解，不能沿用。

## 4. trigger 语义

1. `trigger=0`：执行 `nav`。
2. `trigger=1` 时检查安全门：
   - 肩部到物体水平距离 0.45–0.70 m，物体在机身系方位 ±45°（±45° 是扫描上限，实际可能更宽），物体高度在场景范围内；这是用户定的初值，技能实测后可调；
   - 底盘速度低于宽松上限 0.3 m/s（Isaac 实测从约 0.26 m/s 刹停滑行 2.6 cm）。
3. 门不通过：无效触发，奖励 −0.1，照常执行当步 `nav`【默认】，回合继续。
4. 门通过：发零速度刹停 settle，直到线速度 < 0.05 m/s 且角速度 < 0.1 rad/s，最多 1.5 s；然后**复查包络**。
   - 滑出包络：算无效触发，回合继续；
   - 仍在包络内：从停稳后的真实位姿执行冻结技能，回合终止（一次触发结束，不重试）。
5. 在 Dreamer 看来，这是一个终止式外部技能宏动作，宏动作内部的步数和物理耗时必须单独记录。
6. 终止帧用刹停后、夹取前的画面，不让观测直接看到结果【默认】。
7. 450 步超时算截断（`is_last=True, is_terminal=False`），评测指标计为失败。
8. 不加触发冷却【默认】。trigger 头初始偏向“继续”【默认】，只在 v4 配置里生效。
9. 动作平滑只作用于连续 `nav`，不作用于离散 trigger。

## 5. 成功定义和奖励

**成功**：物体抬离支撑面 ≥5 cm，保持 ≥2 s，无掉落，除手指接触目标外无碰撞，15 s 内完成。`picked=True` 只是内部事件，不能算成功。

| 项 | 值 |
|---|---|
| 成功 | +20 |
| 失败 | −F，F 先取 5，之后比较 5/10/20 |
| 无效触发 | −0.1 |
| 碰撞 | −2 |
| 时间 | −0.01/步 |
| 距离势函数 | 只用目标位置，不含角度；严格折扣势差 |
| q\* 势函数 | 见下 |

- 势差统一用 γ = 332/333；真终止时 Φ=0，该步 shaping 为 −Φ(s)；截断不归零。
- 触发代价的简化比较（手算，未计 shaping）：一直不触发的价值约 −3.33，F=5/10/20 时不值得夹的成功率线约为 6.7%/22%/42%。这不是触发阈值的保证。必须监控超时不触发的比例。

### q\* 的用法
- q\* 用物体真实位姿计算站位质量，**不进观测，不进安全门，不进部署**。
- **主线**：按最近 N 个回合的真实夹取成功率退火到 0，只降不升；不能看总 reward，因为总 reward 里包含 q\* 自身。默认 N=200，成功率 20%→50% 时权重从 1 线性降到 0【默认，待用户确认】。
- 权重到 0 后继续训练，确认成功率不掉。
- 任务奖励和 Φ 分开存入 replay，训练时按当前权重现算奖励【默认】。
- **必跑对照**：同预算纯无 q\*，由它决定“自主”能说到什么程度；固定 q\* 作参考。
- **备选**：撤掉 q\* 后成功率掉下来，再试可行性势函数（用可行性头的预测代替 q\*）。

| 结果 | 论文可以写 |
|---|---|
| 纯无 q\* 学得会 | 世界模型从夹取成败中自主学会选角度 |
| 只有退火版学得会，撤掉后不掉 | q\* 只作前期课程，最终策略不依赖它 |
| 只有固定 q\* 学得会 | 在角度引导下学会，不写“自主” |

## 6. 可行性辅助头

- 世界模型加一个头，预测“从当前状态触发能否成功”。只作辅助损失，不作策略输入。
- 标签来自冻结技能的反事实执行，只在门内抽样。kin 阶段用代替模型，复用并改造 `AffordanceLabeler`（v3 worktree 的环境内实时标注可参考，不要直接合并）。
- 到 Isaac 后，保存和恢复环境的成本要实测，再决定是否保留。
- 结果中三个量分开：q\*（真值，只用于奖励）、q̂（估计位姿算出）、ŝ（学出来的成功率预测）。

## 7. 冻结夹取技能

- 流程：脚本老师 → DAgger 深度学生 → 残差 PPO，基于 `depth-mani/airbot_rl`。**复制后改造**，不改原目录。
- 与原工程的差异：
  - 趴姿 M1 → 站姿 A2（0.385 m）；
  - 地面易拉罐 → 桌面扁盒和圆柱的水平侧抓；
  - 成功判据改为 §5。
- 输入：头部 + 腕部深度 + 本体感知。桌上只有目标，所以不加目标位置输入。
- 转腕：允许补偿接近偏角，±15°（用户 2026-11-05 定）。用户选定范围内的实测（`audit_geometry/v2/`）：所有桌边可用时，最近桌边正对 36.8%、斜站 52.1%、必须换桌边 7.4%、不可解 3.7%。
- 仿真：Isaac 求解器用默认 4/0（用户定）。此设置下带臂站高约 0.376 m，比 kin 的 0.385 m 低约 9 mm，换真实技能时要对齐。不加相机和支架质量（用户定）。
- 手臂驱动：沿用 `airbot_rl` 按真机录像辨识的 PD 和指令延迟（验证 MAE 0.0039 rad）。没有实测的关节摩擦数据：DISCOVERSE 模型的 frictionloss 15/5 N·m 会让手臂撑不住（力限只有 24/8 N·m），所以设为 0；SDK 文档站目前打不开。`airbot_rl` 关掉了手臂重力，但 A2 底盘要承受手臂重量，所以保留重力并加重力补偿力矩【默认】。已实测：用 `root_physx_view.get_gravity_compensation_forces()` 加到 `set_joint_effort_target` 后，末端误差从 13–17 mm 降到 0.12 mm，力矩都在限幅内，底盘指标基本不变。
- 底盘：**一开始就用站立控制器**（UniLab `A2JoystickFlat`，MuJoCo 训练，本机 `/Users/amiao/UniLab/logs/rsl_rl_ppo/A2JoystickFlat/2026-08-20_17-29-21_mujoco/policy.onnx`）。如果撑不住，停下来问用户，不要自行换成固定底盘。已实测站稳（W2）：求解器 4/0、新 STOW、联合随机化 324 env 0 摔倒，肩部偏移最大 6.6 mm。训练时的推力只有 ≤1 N，几乎不起作用；抓取时的抗推能力没有经过训练验证（速度冲击压力测试：Δv 0.5 m/s 也没摔，但肩部最大位移 111 mm）。
- 初始状态分布必须覆盖安全门集合和 settle 后的残余速度。
- 冻结范围：actor、encoder、预处理、状态初始化、动作缩放、控制频率。

kin 代替模型：从停稳的真实位姿重新规划，全程底盘锁定，检查“抬起并保持”。不能只把 `ManipController` 的 cap 设为 0（yaw 修正和高度搜索仍在起作用）。kin 的 `GRASP_P=0.92` 和规则判定不能当作真实成功率。

## 9. 评测

**v1 成功标准**：全回合成功率明显高于“走到最近站位就夹”；扁盒的触发角集中在可夹扇区；去掉记忆后明显变差。recurrent PPO 作对照，不要求一定赢。“明显”的统计口径待用户定。

**基线**：最近站位、特权几何上界、Dreamer + 规则触发（q\* 版只在仿真中作参考）、recurrent PPO。用户决定**不加**可部署的经典流水线基线。

**消融**：纯无 q\*、固定 q\*、去掉可行性头、真正无历史的模型（只把 deter 清零不算）、去掉腕部深度、F=5/10/20。

**指标**：全回合成功率为主；另报触发覆盖率、触发后条件成功率、无效触发率、超时不触发比例、路径长度、导航时间、刹停时间、技能内部步数和耗时、碰撞和掉落比例。

**分层**：形状、桌高、好面是否一开始可见、朝向是否有歧义、被挡桌边数量。

所有方法使用同一个技能、同一个成功判据、同一个场景分布；多个随机种子，留出未见布局。

## 10. 已知风险

- **记忆可能没什么用**：目标位置已知且桌上只有一个物体。带噪声实测（a=0.004、3% 空洞）：头部单帧在 0.75 m 内能靠模板匹配分出 ±45° 镜像（准确率 1.0），1.5 m 外接近随机；腕部在抓取站位仍看得到物体。记忆的作用主要是记住被挡的边和远处看到的信息。W7 差距小或去掉记忆没差异时，先改场景。
- **可解场景可能很少**：长边与桌边平行、离桌边 5–15 cm 的扁盒，手算最小偏角约 23–32°。
- **可能学成永不触发**：见 §5。
- **站立控制器**：没有训练过手臂运动的反作用。
- **v3 的 XLA 报错**：`Contracting dimension is too fragmented` 原因未查清，v4 首次 GPU 冒烟时重点看。
